# Tools

## Retki Planner

`retki-planner/index.html` is an expedition cost and preparation planner. It is one HTML file with no build step.

- **Trip**: dates, group size, season, temperature, activities
- **Group**: names, diets, health notes, swimming ability
- **Costs**: cost rows, safety buffer, client price, second currency
- **Food**: calories, food weight, fuel, meal plan
- **Gear**: suggested gear per activity, packing checklist, sharing out group gear
- **Route**: daily distances and time estimates
- **Safety**: risk assessment, emergency plan and numbers, first aid kit
- **Timeline**: preparation tasks with dates
- **Notion & backup**: copy the plan as Markdown or CSV for Notion, or save a JSON backup

Data is saved in the browser (localStorage). Open the file in a browser to use it, or host it (for example with GitHub Pages) and embed it in Notion with `/embed`.
